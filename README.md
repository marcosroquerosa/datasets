# 📂 Datasets

Esta pasta contém os datasets utilizados nos projetos de análise de dados deste repositório.

Os dados aqui presentes são utilizados para fins de estudo, experimentação e desenvolvimento de habilidades em Ciência de Dados.

---

## 🎯 Objetivo

Organizar e disponibilizar conjuntos de dados utilizados em:

- Análise exploratória de dados (EDA)
- Limpeza e tratamento de dados
- Visualização de dados
- Modelagem estatística e Machine Learning
- Projetos acadêmicos e exercícios práticos

---

## 📁 Estrutura

Cada dataset pode estar acompanhado de:

- Arquivo original (`.csv`, `.xlsx`, `.json`, etc.)
- Versões tratadas (`*_clean.csv`, `*_processed.csv`)
- Documentação auxiliar (quando necessário)

## ⚠️ Observações Importantes

- Alguns datasets podem conter dados incompletos, inconsistentes ou simulados
- Os dados NÃO devem ser considerados fontes oficiais
- O objetivo principal é aprendizado e prática
